# agent

[![Lines of code](https://img.shields.io/endpoint?url=https%3A%2F%2Fancaria.dev%2Ffiles%2Fbadges%2Fagent.json)](https://github.com/ancaria-dev/agent)

The JavaScript that ancaria injects into Sacred Gold, for anyone who adds a hook
or an event to the loader.

Frida runs the agent inside the game process. It hooks the game's functions,
reports what happens as events, asks mods whether to allow an action, and
carries out their commands. The Rust host in
[protocol](https://github.com/ancaria-dev/protocol) carries those messages
between the game and the mods' JVM.

Every game address comes from [mappings](https://github.com/ancaria-dev/mappings)
and targets `pureHD.exe` 2.0.2.118. A release bakes the addresses in and ships
the agent minified as `agent.zip`. The launcher downloads it, so you never
install it by hand to play.

## Getting started

To run your own agent in the game:

1. Clone [mappings](https://github.com/ancaria-dev/mappings) beside this
   repository, or let `tools/addr.py` download it.
2. Create `.local.settings` with the game folder:
   `sacred=D:\SteamLibrary\steamapps\common\Sacred Gold`.
3. Run `pwsh tools/install.ps1`. It generates the addresses, packs the agent,
   and replaces `<game>/launcher/agent/`.
4. Start the game from the launcher. Close it first if it runs: a running
   game keeps its old agent.

Before a new hook ships, run `python tools/hooksafe.py` against your game.
[docs/RUNNING.md](docs/RUNNING.md) shows how to bisect a crash down to one
module or one site.

## What's inside

| Path | What it is |
|---|---|
| `src/NN-name.js` | The modules. They share one scope and load in file-name order. |
| `src/gen/addr.js` | The address table, generated by `tools/addr.py` and never committed. |
| `signatures.json` | The instruction bytes at every hook site, written by `tools/hooksafe.py --signatures`. |
| `tools/compact.mjs` | The minifier: it removes comments and layout and changes nothing else. |
| `tools/pack.mjs` | Builds `dist/agent/` and `dist/agent.zip`. |
| `tests/` | The build check, the minifier tests, and an injection through frida-python. |

## agent.zip

The archive is flat and already minified:

```
addr.js       the address table
NN-name.js    every module
hooks.json    the hook sites per module, which the launcher shows as toggles
agent.json    {"version":"<version>","protocol":1}
```

The host refuses an agent whose `protocol` differs from its own number. That
keeps an old host from loading an agent that speaks different messages.

## Building

You need Python 3.11 and Node 24. `tools/hooksafe.py` also needs `pefile` and
`capstone`. Nothing else is installed.

```
python tools/addr.py              writes src/gen/addr.js
python tools/hooksafe.py          refuses hook sites a trampoline would corrupt
node tests/buildcheck.js          checks the build warning against a fake game
node --test "tests/*.test.mjs"    tests the minifier and the hook reader
node tools/pack.mjs               writes dist/agent.zip
```

`addr.py` looks for `mappings.json` in this order: a path argument,
`$AGENT_MAPPINGS`, the sibling `../mappings`, then GitHub at the revision in
`.mappings-ref`.

## Releases

A release is the `Release` button in Actions: you enter a version and,
optionally, the mappings version to bake in. Empty means the latest mappings
release. The workflow checks the registry, runs the tests, and attaches
`agent.zip` to a GitHub Release.

[devops](https://github.com/ancaria-dev/devops) starts this release after every
mappings release and then updates the launcher's manifest. The root
[CONTRIBUTING](https://github.com/ancaria-dev/.github/blob/master/CONTRIBUTING.EN.md)
has the details.
